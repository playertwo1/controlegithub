# Contribuição

Leia `AGENTS.md`, descreva o problema e mantenha o diff focado.
Execute build, testes unitários e lint. Para mudanças na navegação, execute
o teste instrumentado com emulador. Registre o que executou e o que ficou NOT_RUN.
Atualize imagens apenas quando a interface mudar; não inclua dados privados.

PRs devem descrever problema, comportamento resultante e evidência.
Mudanças relevantes recebem auditoria independente antes de serem consideradas
concluídas. Não altere resultados para ocultar erros.
