# C22.1 — Markdown de leitura (OH-03)

## Escopo

- Renderizador Markdown em Compose (títulos, ênfase, listas, citações, código inline/bloco, tabelas simples, links, imagens como link) sem WebView.
- Links: somente `https`; links do GitHub abrem dentro do app quando houver tela; demais pedem confirmação antes de abrir o navegador.
- HTML bruto é exibido como texto, nunca executado.
- Aplicar em README, corpo de issue/PR e comentários; fallback para texto puro se a análise falhar.

## Pré-condições e decisões

- C21.2 DONE. Pedido do usuário (M5, v2.0). Sem dados de demonstração.

## Aceite

1. **Dado** um README com Markdown, **então** títulos, listas e código aparecem formatados.
2. **Dado** link `javascript:`/`http:`/HTML embutido, **então** não é executado nem aberto sem confirmação.
3. **Dado** Markdown inválido, **então** o texto original é mostrado.
