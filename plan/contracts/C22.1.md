# C22.1 — Markdown de leitura (OH-03)

## Escopo

- Substituir a exibição literal do README, descrição de issue/PR e comentários por um componente Compose reutilizável; nenhuma WebView ou renderização HTML.
- Renderizar títulos, parágrafos, ênfase, listas ordenadas/não ordenadas, citações, código inline/bloco, separadores e tabelas GFM simples. Conteúdo continua selecionável e legível com fonte ampliada.
- Mostrar HTML bruto literalmente. Para imagem Markdown, mostrar texto alternativo como link, sem baixar ou exibir mídia remota.
- `commonmark-java` 0.30.1 e `commonmark-ext-gfm-tables` 0.30.1, licença BSD 2-Clause; parser limitado a 256 Ki caracteres, até 4.096 nós AST e níveis de nesting/block parser até 100. Sob qualquer limite excedido ou erro, exibir a entrada integral em texto puro.
- Validar links antes de criar interação: somente URI HTTPS absoluta, host válido, sem userinfo e porta ausente/443. Esquemas inseguros, URI malformada e relativos sem resolução confiável ficam como texto sem ação.
- Rotear para dentro do app apenas `github.com/{owner}/{repo}`, `/issues/{n}` e `/pull/{n}` quando owner/repo/identificador forem inequívocos. A pilha de detalhes preserva a tela de origem e Back retorna ao destino anterior; ciclos reutilizam a rota existente, a pilha aceita até 10 destinos e informa quando esse limite é atingido. Ao expirar ou trocar a sessão, limpar a pilha para não expor nem ressuscitar destinos da sessão anterior.
- Outros links HTTPS e caminhos do GitHub sem tela nativa exibem confirmação com domínio/destino antes de `ACTION_VIEW`. Nenhuma requisição autenticada é feita ao destino; nunca anexar token.
- Nenhum envio/mutação, renderização remota, HTML ativo, execução de script, carregamento de imagem ou Android App Link.

## Pré-condições e decisões

- C21.2 está DONE para implementação e emulador; aceite físico está explicitamente adiado e permanece NOT_RUN em C21.3. Essa pendência não impede C22.1, cuja dependência individual é C21.2.
- A direção OH-03/OH-05 do estudo aprovado localmente limita conteúdo ativo, exige ação explícita para fallback externo e proíbe adivinhar a resolução de links relativos. O roteador aqui cobre somente os três destinos nativos definidos acima.
- `commonmark-java` fornece AST para renderização própria e parser configurável; a extensão de tabelas cobre GFM sem conversão para HTML. Compose deste projeto usa BOM 2024.12.01 e oferece `LinkAnnotation` para links inline acessíveis.
- Fontes técnicas conferidas em 2026-10-22: [commonmark-java releases](https://github.com/commonmark/commonmark-java/releases), [README e licença do commonmark-java](https://github.com/commonmark/commonmark-java), [Compose LinkAnnotation e seleção](https://developer.android.com/develop/ui/compose/text/user-interactions).

## Aceite

1. **Dado** README, corpo de issue/PR, comentário ou review com Markdown suportado, **quando** a tela carrega, **então** headings, ênfase, listas, citações, código e tabela são renderizados pelo mesmo componente Compose e o texto pode ser selecionado/copiado.
2. **Dado** HTML bruto, entrada acima do limite, falha do parser, URI relativa ou esquema diferente de HTTPS, **quando** renderizada, **então** o conteúdo permanece texto literal/legível e nenhuma ação externa, execução ou busca de mídia ocorre.
3. **Dado** URL HTTPS canônica de repositório, issue ou PR GitHub com identificador válido, **quando** tocada, **então** abre o detalhe interno correto; Back retorna ao detalhe/tela que continha o link, sem perder a tela de origem. Destinos já presentes na pilha são reutilizados; ao chegar a 10 destinos únicos, nova navegação informa que o usuário deve voltar para continuar. Expiração ou troca de sessão limpa as rotas retidas.
4. **Dado** host semelhante (`github.com.evil.test`), userinfo, porta inesperada, número inválido ou esquema inseguro, **quando** tocado, **então** o link fica inerte; caminho GitHub sem detalhe suportado e HTTPS externo exigem confirmação explícita antes do navegador. Nenhuma credencial segue para o navegador.
5. **Dado** imagem remota Markdown, **quando** exibida, **então** aparece o texto alternativo; tocar nele aplica as mesmas regras de link e não baixa imagem automaticamente.

- Testes instrumentados Compose para conteúdo Markdown e confirmação/negação de links, imagens sem carregamento, navegação interna com Back preservando a origem e limpeza de rotas quando a sessão expira.
