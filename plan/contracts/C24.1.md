# C24.1 — Navegador de código

## Escopo

- Árvore via `GET /repos/{o}/{r}/contents/{path}?ref=` com navegação por pastas e breadcrumb.
- Visualizador de texto com números de linha e destaque de sintaxe para linguagens comuns (Kotlin, Java, JS/TS, Python, JSON, XML, YAML, Markdown via C22.1); binários/arquivos grandes mostram aviso e link.
- Seletor de ref: branches (`/branches`) e tags (`/tags`), padrão = branch padrão.

## Pré-condições e decisões

- C23.1 DONE. Pedido do usuário (M5, v2.0). Sem dados de demonstração.

## Aceite

1. **Dado** um repositório, **então** navego pastas e abro arquivos de texto com destaque.
2. **Dado** troca de branch ou tag, **então** a árvore recarrega naquela ref.
3. **Dado** arquivo binário ou > 1 MB, **então** vejo aviso em vez de conteúdo quebrado.
