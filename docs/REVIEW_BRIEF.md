# Pacote para auditoria independente

## Pedido

Iniciar `playertwo1/controlegithub` como app Android inspirado no GitDeck,
seguindo o template de `playertwo1/ideias_standard`, com roadmap e imagens de
telas finais. Preferências posteriores: inspiração One UI e menus flutuantes.

## Aceite da fundação

- Projeto abre e gera APK debug; busca e navegação verificadas.
- README, AGENTS, estado, roadmap, manifests e lock compatíveis com Gold LIGHT.
- 36 telas/estados conceituais e seis capturas reais, diferenciados claramente.
- Menu flutuante no protótipo e nas referências; quatro destinos consistentes.
- Nenhum login fictício apresentado como integração concluída.
- Build, testes, lint e resultados do Standard reproduzíveis.

## Delta

Repositório inicialmente vazio. O primeiro commit contém toda a fundação.
Começar por README, diff do commit, `docs/VERIFICATION.md`, build/manifest,
`DemoData.kt`, navegação, testes e contrato visual. Expandir apenas para hipóteses.

## Atenção

Não avaliar propostas de F1–F4 como implementadas. Conferir separação de imagens
conceituais e capturas. Verificar autoria/estado da auditoria, versões fixadas,
limites de API testados e ausência de segredos. Resultado esperado: PASS ou FAIL
