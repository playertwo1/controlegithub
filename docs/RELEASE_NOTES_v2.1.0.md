# Notas de Lançamento — ControleGitHub v2.1.0

**Versão:** 2.1.0 (`versionCode = 102`)

**Data:** 24 de outubro de 2026

**Distribuição:** [GitHub Releases](https://github.com/playertwo1/controlegithub/releases)

## O que mudou nesta versão

- **Ações diretas em Avisos:**
  - Botões dedicados **"Abrir repositório"** e **"Releases e APKs"** agora aparecem nos cartões e no detalhe de qualquer aviso que tenha repositório válido, inclusive notificações de Issue, Pull Request, Release e outros tipos.
  - Permite acessar diretamente o repositório (README, Código, Actions, Nova issue) e ir direto para o download e instalação manual de APKs sem etapas intermediárias.
- **Novo ícone adaptativo (Adaptive Icon):**
  - Ícone moderno em camadas (`@mipmap/ic_launcher` e `@mipmap/ic_launcher_round`) com gradiente escuro e grafo Git vetorial em azul/ciano.
  - Ícone monocromático específico para notificações do sistema Android (`@drawable/ic_stat_notification`).

## Compatibilidade

Esta versão utiliza o mesmo certificado de assinatura da versão 2.0.0 (`c622fc491da08aee1b9e196db0cc7ba92784eefc02c047c387049042ad0aa2ec`), permitindo atualização direta sem necessidade de desinstalar se você já estiver na 2.0.0.
