## Limite do aceite

O endpoint gerou códigos reais, mas eles não foram usados para autorizar uma
sessão; C02 verifica configuração e solicitação de código, enquanto login é C03.

## Limite de segurança a reavaliar

O Device Flow permanece no escopo atual do roadmap. A documentação do GitHub
recomenda PKCE para clientes nativos e alerta sobre risco de phishing no Device
Flow; revisar antes de disponibilizar autenticação a outras pessoas. Isto não
foi alterado silenciosamente nesta entrega.
