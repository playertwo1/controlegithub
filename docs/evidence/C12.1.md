## Implementação

- **Suporte a POST no Cliente HTTP (`GitHubHttpClient.kt`):**
  - Adicionado método `post(path: String, accessToken: String? = null, jsonBody: String? = null): GitHubHttpCall`.
  - Validação estrita de caminho (origem idêntica, sem fragmento ou path traversal).
  - Envio com `doOutput = true`, cabeçalho `Content-Type: application/json; charset=utf-8` e `setFixedLengthStreamingMode` para eficiência de memória sem buffering desnecessário.
- **Camada de Domínio e Serialização Segura (`GitHubIssues.kt`):**
  - Implementada função `escapeJson(value: String): String` para sanitização pura Kotlin sem dependências externas.
  - Implementada função `createGitHubIssue(client, accessToken, repository, title, body, isOffline)` com os resultados modelados em `CreateIssueResult`:
    - `Success(val issue: GitHubIssue)`
    - `Failure(val error: GitHubHttpError, val statusCode: Int? = null)`
    - `EmptyTitle`
    - `Offline`
  - Implementado analisador `parseCreatedIssue(json, fallbackRepository)` para mapear a resposta `201 Created` do GitHub para a entidade de domínio `GitHubIssue`.
- **Interface de Criação de Issue (`GitHubCreateIssueScreen.kt`):**
  - Tela completa em Jetpack Compose com UI 100% em português.
  - **CREATE-01 (Envio e Confirmação):** Campo de título obrigatório e descrição opcional; envio de `POST /repos/{owner}/{repo}/issues` com corpo `{"title":"...","body":"..."}` e callback `onIssueCreated` disparado no sucesso (201 Created).
  - **CREATE-02 (Anti-duplo clique):** Botão "Criar issue" desabilitado imediatamente no primeiro clique, com exibição de `CircularProgressIndicator` e texto "Criando..." até a conclusão ou retorno de erro.
  - **CREATE-03 (Preservação do Rascunho):** Em caso de falha de rede, timeout, 403 (permissão insuficiente) ou erros de servidor, o texto do título e da descrição é integralmente preservado nos campos (`rememberSaveable`), permitindo nova tentativa sem retrabalho.
  - **CREATE-04 (Validação Local):** Submissão com título vazio ou em branco é bloqueada localmente antes de qualquer chamada de rede, exibindo "O título da issue não pode ficar em branco.".
  - **CREATE-05 (Bloqueio no Modo Offline):** Quando detectado modo offline, exibe banner informativo vermelho de indisponibilidade e desabilita campos e botão de submissão (sem fila oculta de mutações).
- **Integração de Navegação (`GitHubRepositoryDetailScreen.kt`):**
  - Adicionado botão "Nova issue" na visualização de detalhes do repositório.
  - Navegação fluida para `GitHubCreateIssueScreen` com suporte a `BackHandler` e cancelamento seguro sem disparar requisições.

### Detalhamento dos Testes de C12.1

1. **`CreateIssueTest` (5 testes unitários na JVM):**
   - `createIssueEmptyTitleReturnsEmptyTitleWithoutNetworkCall`: Valida bloqueio de títulos vazios sem tráfego de rede.
   - `createIssueOfflineReturnsOfflineWithoutNetworkCall`: Valida rejeição instantânea quando `isOffline = true`.
   - `createIssueForbiddenReturnsFailure`: Valida mapeamento do erro 403 Forbidden.
   - `createIssueNotFoundReturnsFailure`: Valida mapeamento do erro 404 Not Found.
   - `escapeJsonEscapesQuotesBackslashesAndNewlines`: Valida escape seguro de caracteres especiais em strings JSON.
2. **`CreateIssueAndroidTest` (3 testes instrumentados no Android runtime / ART):**
   - `parseCreatedIssueMapsFieldsCorrectly`: Valida decodificação de JSON completo retornado pela API do GitHub para `GitHubIssue`.
   - `parseCreatedIssueHandlesMissingRepositoryByFallback`: Valida resiliência de parsing quando o objeto `repository` não é retornado pelo endpoint.
   - `parseCreatedIssueRejectsMissingTitleOrNumber`: Valida rejeição de payloads com campos obrigatórios ausentes.
3. **`CreateIssueUiTest` (5 testes instrumentados de UI Compose no Pixel 9):**
   - `createIssueSuccessSubmitsPostAndInvokesCallback`: Comprova que preencher título e corpo envia `POST /repos/acme/app/issues` com JSON válido e autorização `Bearer`, recebendo 201 Created e invocando callback de sucesso com a issue criada (CREATE-01).
   - `createIssueAntiDoubleTapDisablesButtonDuringSubmission`: Comprova desabilitação imediata do botão e exibição de indicador de progresso durante a requisição (CREATE-02).
   - `createIssueFailureDisplaysErrorAndPreservesDraft`: Comprova exibição de mensagem descritiva de erro (403 sem permissão) e preservação exata dos textos preenchidos nos campos de título e descrição (CREATE-03).
   - `createIssueEmptyTitleShowsValidationErrorWithoutNetworkCall`: Comprova mensagem de validação local para título vazio sem disparo de chamada HTTP (CREATE-04).
   - `createIssueOfflineModeDisablesSubmissionAndShowsBanner`: Comprova banner de alerta offline e desabilitação de submissão no modo sem conexão (CREATE-05).
