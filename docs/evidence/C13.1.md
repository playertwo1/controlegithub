## Implementação

- **Camada de Domínio e Modelo de Dados (`GitHubPullRequests.kt`):**
  - Implementado tipo selado `CreatePullRequestCommentResult`:
    - `Success(val comment: GitHubPullRequestComment)`
    - `Failure(val error: GitHubHttpError, val statusCode: Int? = null)`
    - `EmptyBody`
    - `Offline`
  - Implementado analisador `parseCreatedPullRequestComment` decodificando a resposta `201 Created` do GitHub (`id`, `user.login`, `body`, `created_at`).
  - Implementada função `createPullRequestComment(client, accessToken, repository, pullNumber, body, isOffline)`:
    - Validação local de comentário vazio/em branco retornando `EmptyBody` antes de qualquer tráfego HTTP.
    - Validação de modo offline retornando `Offline` sem tráfego HTTP.
    - Rota REST autenticada: `POST /repos/{owner}/{repo}/issues/{pull_number}/comments`.
    - Sanitização segura de JSON via `escapeJson`.
- **Interface e Interações (`GitHubPullRequestsScreen.kt`):**
  - Desenvolvida em Jetpack Compose com UI 100% em português brasileiro.
  - **COMMENT-01 (Envio de comentário no PR com sucesso):** Formulário com `OutlinedTextField` (`pr_comment_input`) e botão `Button` (`pr_comment_submit_button`). Ao submeter com resposta `201 Created`, o comentário é anexado à lista visível e o campo de texto é limpo.
  - **COMMENT-02 (Anti-duplo clique no PR):** Botão de envio desabilitado síncronamente no primeiro clique com exibição de `CircularProgressIndicator` (`pr_comment_progress`), impedindo submissões duplicadas.
  - **COMMENT-03 (Preservação de rascunho de comentário em falha):** Em falhas de rede, 403 Forbidden ou erro de servidor, o texto digitado é preservado intacto no campo e uma mensagem clara de erro é exibida (`pr_comment_error`).
  - **MUTATION-GUARD (Validação local e bloqueio offline):** Tentativas de submissão com campo vazio exibem erro local sem emitir requisição HTTP. Em modo offline (`isOffline = true`), o formulário de envio é substituído pelo banner informativo `pr_comment_offline_banner` ("Modo offline: Conexão necessária para comentar em pull requests.") sem fila de escrita offline.
